# Telegram AI Bot - Инструкция по установке и запуску

## 📋 Требования

- Python 3.9+
- Telegram Bot Token (получить у @BotFather)
- Hugging Face API Key (бесплатно на huggingface.co)

## 🔧 Установка

### 1. Клонирование/Копирование проекта

Убедитесь, что все файлы находятся в папке `bot/`.

### 2. Создание виртуального окружения

```bash
cd bot
python -m venv venv
```

### 3. Активация виртуального окружения

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/Mac:**
```bash
source venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

Откройте `.env` и заполните:

```env
# Telegram Bot Token - получите у @BotFather
TELEGRAM_BOT_TOKEN=your_bot_token_here

# Hugging Face API Key - получите на https://huggingface.co/settings/tokens
HUGGINGFACE_API_KEY=your_hf_api_key_here

# Ваш Telegram ID для админ-панели (узнайте у @userinfobot)
ADMIN_ID=123456789

# Остальные настройки можно оставить по умолчанию
DATABASE_URL=sqlite+aiosqlite:///bot.db
DEFAULT_MODEL=meta-llama/Meta-Llama-3-8B-Instruct
FALLBACK_MODEL=google/gemma-2b-it
MAX_REQUESTS_PER_DAY=100
MAX_CONTEXT_MESSAGES=20
MAX_MESSAGE_LENGTH=4000
```

## 🚀 Запуск бота

```bash
python run.py
```

Или:

```bash
python main.py
```

## 📱 Получение токенов

### Telegram Bot Token

1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте полученный токен

### Hugging Face API Key

1. Зарегистрируйтесь на https://huggingface.co
2. Перейдите в Settings → Tokens
3. Создайте новый токен с правами "read"
4. Скопируйте токен

### Ваш Telegram ID

1. Откройте @userinfobot в Telegram
2. Нажмите Start
3. Скопируйте ваш ID

## 🔐 Админ-панель

Доступна только пользователю с ADMIN_ID из .env

Команда: `/admin`

Функции:
- 📊 Статистика бота
- 👥 Список пользователей
- ⚠️ Просмотр ошибок
- 📩 Рассылка сообщений
- 🚫 Блокировка пользователей
- ✅ Разблокировка пользователей

## ⚠️ Обработка ошибок

Бот автоматически обрабатывает:
- Превышение лимитов API
- Таймауты соединения
- Недоступность моделей
- Слишком длинные сообщения
- Ошибки базы данных

При ошибке пользователь видит понятное сообщение, а техническая информация сохраняется в логах.

## 📊 Лимиты

По умолчанию:
- 100 запросов в день на пользователя
- Максимум 4000 символов в сообщении
- 20 сообщений контекста

Настройте в `.env`:
```env
MAX_REQUESTS_PER_DAY=100
MAX_MESSAGE_LENGTH=4000
MAX_CONTEXT_MESSAGES=20
```

## 🗄 База данных

Бот использует SQLite (файл `bot.db`).

Автоматически создаются таблицы:
- users - пользователи
- chat_history - история чатов
- favorites - избранное
- usage_stats - статистика
- error_logs - логи ошибок

## 🔄 Обновление

1. Остановите бота (Ctrl+C)
2. Обновите код
3. Запустите снова: `python run.py`

База данных сохранится.

## 🛠 Troubleshooting

### Бот не запускается
- Проверьте, что `.env` файл существует и заполнен
- Убедитесь, что зависимости установлены: `pip install -r requirements.txt`
- Проверьте токен бота у @BotFather

### AI не отвечает
- Проверьте API ключ Hugging Face
- Некоторые модели могут быть временно недоступны
- Попробуйте выбрать другую модель в настройках

### Ошибка базы данных
- Удалите файл `bot.db` и перезапустите бота
- Данные будут потеряны, но бот заработает

### Превышен лимит
- Дождитесь следующего дня
- Или увеличьте лимит в `.env`
